# Plan 02-01: Scaffold Standalone ProfileComponent and Header Trigger

<objective>
Scaffold a modular, standalone Angular 20 `ProfileComponent` in `frontend/src/app/components/profile/` per PROF-01, avoiding bloat in `app.ts`. Integrate the profile trigger button in the main application header per PROF-02, showcasing active role badge and opening the centered frosted-glass profile modal with high-polish aesthetics from `frontend-ui-architect`.
</objective>

  <behavior>
    - ProfileComponent is standalone with selector 'app-profile'
    - Accepts inputs: isOpen (boolean), activeRole (UserRole)
    - Emits outputs: roleChange (EventEmitter<UserRole>), close (EventEmitter<void>)
    - Displays user card: Alex Mercer, alex.mercer@taskflow.dev, avatar icon
    - Displays 3 selectable role cards: ADMIN, MEMBER, VIEWER with icons and descriptions
  </behavior>
  <action>
    1. In frontend/src/app/models/taskflow.model.ts:
       - Export `export type UserRole = 'ADMIN' | 'MEMBER' | 'VIEWER';`
       - Export `export const ALL_ROLES: UserRole[] = ['ADMIN', 'MEMBER', 'VIEWER'];`
    2. Create `frontend/src/app/components/profile/profile.component.ts`:
       - Standalone component with `CommonModule`.
       - Inputs: `isOpen = input<boolean>(false); activeRole = input<UserRole>('MEMBER');`
       - Outputs: `roleChange = output<UserRole>(); close = output<void>();`
       - Method `selectRole(role: UserRole)` emitting `roleChange`.
       - Method `onClose()` emitting `close`.
    3. Create `frontend/src/app/components/profile/profile.component.html`:
       - Overlay wrapper with backdrop click handler.
       - Modal container with header, close button (`✕`), user details section (Alex Mercer, Senior Engineer, alex.mercer@taskflow.dev).
       - Simulated Role Context section featuring 3 clickable cards (`👑 ADMIN`, `⚡ MEMBER`, `👁️ VIEWER`) with capability descriptions.
       - Active card marked with selected class and checkmark indicator.
    4. Create `frontend/src/app/components/profile/profile.component.css`:
       - Modern styling per `frontend-ui-architect`:
       - Frosted glass backdrop `backdrop-filter: blur(8px)`.
       - Layered slate cards (`#1e293b`), 1px borders `rgba(255, 255, 255, 0.08)`.
       - Interactive hover lift `translateY(-2px)` and active scaling `scale(0.98)`.
       - Semantic accent colors: Admin (`#f59e0b`), Member (`#10b981`), Viewer (`#0ea5e9`).
  </action>
  <verify>
    <automated>npm run build:frontend</automated>
  </verify>
