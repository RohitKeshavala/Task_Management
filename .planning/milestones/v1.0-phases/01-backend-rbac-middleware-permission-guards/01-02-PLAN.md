       - Add `requireRole(['ADMIN', 'MEMBER'])` to PUT `/:id` (update project).

       - Import `requireRole` from `../middleware/auth.js`.

         - DELETE `/:id` (delete task)
         - PATCH `/:id/status` (update task status)
         - POST `/:id/tags` (associate tag)
         - DELETE `/:id/tags/:tagId` (disassociate tag)
         - POST `/:id/dependencies` (add dependency)
         - DELETE `/:id/dependencies/:dependsOnTaskId` (remove dependency)
       - GET `/`, GET `/:id`, and GET `/:id/blockers` remain unguarded.
    3. In backend/src/routes/tagRoutes.ts:
       - Import `requireRole` from `../middleware/auth.js`.
       - Add `requireRole(['ADMIN', 'MEMBER'])` to POST `/` (create tag).
       - Add `requireRole(['ADMIN', 'MEMBER'])` to DELETE `/:id` (delete tag).
       - GET `/` and GET `/:id` remain unguarded.

    - MEMBER role: Can GET all, POST/PUT/DELETE tasks and tags, POST/PUT projects, but receives 403 on DELETE /api/projects/:id.
    - Missing header: Behaves as MEMBER (can GET/POST tasks, receives 403 on DELETE /api/projects/:id).
    - VIEWER role: Can GET projects, tasks, and tags; receives 403 on POST /api/projects, PUT /api/projects/:id, DELETE /api/projects/:id, POST /api/tasks, PUT /api/tasks/:id, DELETE /api/tasks/:id, POST /api/tags, DELETE /api/tags/:id.
    - Invalid role: 'SUPERUSER' or 'GUEST' returns 400 Bad Request with error description.
    - Case insensitivity: 'admin' grants ADMIN permissions; 'viewer' applies VIEWER restrictions.
    - api.test.ts: Line 57 project delete passes with .set('x-user-role', 'ADMIN').
  </behavior>
  <action>
    1. In backend/tests/api.test.ts:
       - In 'should delete project and cascade', add `.set('x-user-role', 'ADMIN')` so that the admin-level delete permission check succeeds.
    2. Create backend/tests/rbac.test.ts:
       - Setup test database via `setupTestDatabase()`.
       - Instantiate app via `createApp()`.
       - Add describe blocks:
         - 'Role Header Parsing and Validation':
           - Empty/missing header defaults to MEMBER.
           - Case-insensitive trimming ('  admin  ' -> ADMIN, 'viewer' -> VIEWER).
           - Invalid role returns 400 Bad Request ({ error: 'Invalid role' }).
         - 'ADMIN Role Permissions':
           - Full access: GET, POST, PUT, DELETE for projects, tasks, and tags.
         - 'MEMBER Role Permissions':
           - Can create project, update project, create task, update task, delete task, create tag, delete tag.
           - Blocked with 403 Forbidden on DELETE /api/projects/:id.
         - 'VIEWER Role Permissions':
           - Can read: GET /api/projects, GET /api/projects/:id, GET /api/tasks, GET /api/tags.
           - Blocked with 403 Forbidden on POST /api/projects, PUT /api/projects/:id, DELETE /api/projects/:id.
           - Blocked with 403 Forbidden on POST /api/tasks, PUT /api/tasks/:id, DELETE /api/tasks/:id.
           - Blocked with 403 Forbidden on POST /api/tags, DELETE /api/tags/:id.
         - '403 Forbidden Error Contract':
           - Responds with statusCode 403 and body { error: 'Forbidden', message: expect.any(String) }.
    3. Run vitest to ensure all tests across all 4 test files pass.
