# Sketch 002: Header Navigation & Filter Hub

## Design Question
How should the top navigation bar and filter toolbar present project switching, search, active filters, and RBAC actions seamlessly?

## How to View
Open `.planning/sketches/002-header-filter-hub/index.html` in your browser.

## Variants
- **A: Integrated Command Bar** — Single unified header integrating brand, pill project selector, global quick search (`⌘K`), RBAC Admin button (`🛡️ Manage Users`), and user role badge.
- **B: Two-Tier Linear Workspace** — Clean separation between Tier 1 (Brand, Projects, Auth/RBAC, Primary Action) and Tier 2 (Sticky contextual filter toolbar with priority dots, tag chips, active count pill, and clear button).
- **C: Compact Studio Bar** — Ultra-dense single-row navigation with segmented project tabs and compact icon controls.

## What to Look For
1. **Vertical Real Estate**: How much vertical space each header uses vs the breathing room it gives to tasks.
2. **Filter Usability**: How easy it is to toggle priority and tag filters.
3. **Role & Governance Prominence**: Clear visibility of `ADMIN` controls (`🛡️ Manage Users`).
