# Plan 03-02: Frontend Authentication Modal, Admin User Management Modal, and Profile Role Switcher Removal

<objective>
Deliver the complete user-facing authentication and role management interface: standalone `AuthModalComponent` with login/signup tabs, standalone `UserManagementComponent` for Admins to view and change member roles, clean up `ProfileComponent` by removing simulated role cards and adding `Log Out`, and wire authentication state across Angular signals, HTTP interceptor, and Jasmine test suites.
</objective>

  <files>
    frontend/src/app/models/taskflow.model.ts,
    frontend/src/app/services/taskflow.service.ts,
    frontend/src/app/services/auth-role.interceptor.ts,

    frontend/src/app/components/user-management/user-management.component.html,
    frontend/src/app/components/user-management/user-management.component.css
  </files>
  <behavior>
    - TaskFlowService provides auth methods: login, register, logout, checkAuth, getAllUsers, updateUserRole
    - AuthModalComponent handles tab switching (Log In vs Sign Up), validation, submission, and quick-fill for demo admin
    - UserManagementComponent fetches users list on open, displays tabular layout, and handles role dropdown change
    - authRoleInterceptor transmits Authorization: Bearer <token> if token exists in TaskFlowService
  </behavior>
  <action>
    1. In frontend/src/app/models/taskflow.model.ts:
       - Export AuthUser, LoginDto, RegisterDto, UserSummary interfaces.
    2. In frontend/src/app/services/taskflow.service.ts:
       - Add currentUser = signal<AuthUser | null>(null);
       - Add authToken = signal<string | null>(null);
       - Implement login(), register(), logout(), getAllUsers(), updateUserRole().
       - Update activeRole to derive from currentUser()?.role || 'MEMBER'.
    3. In frontend/src/app/services/auth-role.interceptor.ts:
       - Inject authToken and add Authorization: Bearer <token> if present.
    4. Create frontend/src/app/components/auth/auth-modal.component (.ts, .html, .css):
       - Standalone component with CommonModule, FormsModule.
       - Tabs: Log In and Sign Up.
       - Demo credentials quick button: "Use Demo Admin" (fills admin@taskflow.dev / Admin123!).
       - Inputs: isOpen. Outputs: authenticated.
    5. Create frontend/src/app/components/user-management/user-management.component (.ts, .html, .css):
       - Standalone component with CommonModule, FormsModule.
       - Table displaying user avatar, name, email, role badge, and role select dropdown.
       - Inputs: isOpen. Outputs: close, userRoleChanged.
  </action>
  <verify>
    <automated>npm run build:frontend</automated>
  </verify>
  <done>AuthModalComponent and UserManagementComponent compile cleanly.</done>
</task>
